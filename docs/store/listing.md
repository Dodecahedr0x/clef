## Description

Clef is a Solana wallet that tells you what a transaction will do before you sign it.

Every request from a site is decoded and simulated. Clef names each program and instruction from its IDL, checks how the accounts relate to each other (PDA seeds, token owners, associated token accounts, Anchor `has_one` links), and shows the balance changes the simulation predicts. Warnings for dangerous patterns — handing over ownership of an account, unlimited delegations, unknown programs, sites on a phishing list — appear at every level and block signing until you acknowledge them.

Choose how much detail you want:

- Basic: one-line summary, balance changes, warnings.
- Intermediate: every instruction, decoded arguments, and the accounts it uses with Clef's verification badges.
- Expert: account-by-account state changes (including raw byte diffs for accounts Clef cannot decode), simulation logs with compute units, the account relationship graph including related accounts outside the transaction, raw instruction data, lookup tables and fees. Requests with several transactions can be viewed one by one or as their combined effect.

Clef is a full wallet:

- Create or import a recovery phrase, import private keys, or watch any address.
- Squads v4 multisig: propose, approve and execute from Clef.
- Send, receive with a QR code, swap through Jupiter, transaction history, address book.
- Mainnet, devnet, local and custom RPC endpoints, with a one-click network switch in Expert mode.
- Bring your own program IDLs for programs Clef does not know yet.

Privacy: Clef has no servers and no analytics. Your keys are encrypted on your device with a password (Argon2id + AES-GCM). Clef only talks to the Solana RPC you choose, Jupiter for prices and swaps, the public phishing list, and — only if you turn it on — an error-report endpoint.

## Single purpose (dashboard field)

Clef is a Solana cryptocurrency wallet: it holds the user's Solana accounts and lets websites request signatures, which Clef explains and the user approves or rejects.
